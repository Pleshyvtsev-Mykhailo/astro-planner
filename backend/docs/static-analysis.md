# Статичний аналіз коду

Інструменти: Roslyn .NET analyzers (рівень latest-recommended) і SonarAnalyzer.CSharp.
Команда: dotnet build --no-incremental

- Рядків коду застосунку (без тестів і міграцій): 1000
- Попереджень аналізатора до виправлень: 23
- Попереджень після виправлень: 0
- На 1000 рядків: 0

Рахувалися всі попередження, а не лише critical/major, тож оцінка суворіша за вимоги.

## Що виправлено
- CA1304, CA1311, CA1862 (10): порівняння імен без урахування регістру переведено на SQLite NOCASE, без ToLower.
- CA1305 (6): явна культура (InvariantCulture) у int.Parse, ToString та логуванні.
- CA1725, S927 (2): назва параметра в OnModelCreating узгоджена з базовим класом.
- S6966 (2): MigrateAsync і RunAsync замість синхронних викликів.
- S1118 (1): захищений конструктор у класі Program (потрібен для інтеграційних тестів).
- S6964 (1): локальне приглушення з поясненням: параметр запиту свідомо необов'язковий, значення за замовчуванням безпечне.
- CA1861 (1): локальне приглушення в згенерованій міграції (код створює EF Core, правити його вручну немає сенсу).

## Що залишено свідомо
Два локальні приглушення правил S6964 та CA1861, кожне з коментарем у коді.
